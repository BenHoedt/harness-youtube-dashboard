Harness · YouTube Dashboard

Enter your YouTube Data API key and Channel ID to load the dashboard. These are saved in your browser only — never sent anywhere except directly to Google's API.

  1. Go to console.cloud.google.com → create a project
  2. Enable YouTube Data API v3
  3. Create credentials → API Key (restrict it to YouTube Data API)
  4. Find your Channel ID in YouTube Studio → Settings → Channel → Advanced

Your credentials are saved in localStorage so you only enter them once per browser. To reset, click the ⚙ button in the dashboard.
